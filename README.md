# Glass Four — ガラスの四目並べ

朝の光の中で遊ぶ、7×6 の四目並べ（2人対戦・1台の端末で交互に操作）。
iPhone / iPad / パソコンのブラウザで動きます。

## 遊び方
- 入れたい列をタップすると、上からガラスのチップが落ちます。
- 縦・横・斜めのどれかに自分の色が4つ並んだら勝ち。
- ドラッグで盤を少し傾けて眺められます。ピンチで拡大・縮小。

## GitHub Pages で公開する
1. このフォルダの `index.html` をリポジトリの一番上に置く
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## アップロードするファイル（すべて同じ階層）
index.html / manifest.webmanifest / apple-touch-icon.png / icon-192.png / icon-512.png / favicon.png / .nojekyll / README.md

iPhone / iPad では Safari で開き、共有ボタン →「ホーム画面に追加」でアイコンから起動できます。
